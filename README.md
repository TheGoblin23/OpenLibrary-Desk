# OpenLibrary Desk
Biblioteca digital local-first en Python (Tkinter + SQLite), sin dependencias externas.

    python main.py                 # ejecutar
    pip install pytest && pytest   # pruebas

Los datos viven en `~/.openlibrary-desk/library.db`. Los archivos nunca se mueven ni se borran.
